# Обработка данных Site Desk

Site Desk запускается на компьютере владельца. Команда подключения сохраняет OAuth-токены и ключи в системном хранилище. Для автоматизации можно передать их через окружение локального процесса. Они используются для обращения к выбранному API. Не помещайте их в чат, GitHub Issues или отчёты.

Агент получает запрошенные сведения о сайте, организации, целях, статистике посещений, идентификаторах и маршрутах. Хранение переписки зависит от настроек клиента агента. Веб-сайт видит обычные HTTP-запросы к его страницам. При обращении к Яндексу соответствующему сервису передаются данные операции. Опциональный запрос в публичный Overpass передаёт координаты и радиус поиска остановок. Сам плагин не использует сервер издателя для этих запросов.

Дежурный режим хранит на устройстве последний успешный снимок полей сайта и выбранных данных кабинетов в SQLite. Закройте процессы Site Desk и удалите каталог данных, если требуется стереть историю сравнений. Команда disconnect удаляет выбранный локальный ключ. Переданные в Яндекс изменения, установленные на сайте счётчики и уже созданные карты управляются в соответствующих кабинетах. Для отзыва доступа отзовите ключ у его издателя.
