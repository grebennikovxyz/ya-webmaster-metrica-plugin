В карточке ClawHub указаны назначение Ya-Webmaster и прямое подключение к выбранным сервисам. Токены и отчёты не передаются издателю.

Для Plugin Creator выберите ZIP. Для локальной команды ya-webmaster используйте wheel. Каталоги Codex, Claude Code и OpenClaw находятся в репозитории. Полный плагин запускается на компьютере пользователя через uvx и обращается к выбранным сервисам напрямую. [Установка и подключение](https://github.com/grebennikovxyz/ya-webmaster-metrica-plugin#установка)
