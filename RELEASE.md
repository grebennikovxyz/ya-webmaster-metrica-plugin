Первый выпуск Site Desk для владельцев сайтов. Включает карточку организации из открытых страниц, операции Вебмастера, цели и метки Метрики, пакет разработчику, IndexNow, карту от остановок и сравнение изменений.

Для Plugin Creator выберите ZIP. Для локальной команды site-desk используйте wheel. Каталоги Codex, Claude Code и OpenClaw находятся в репозитории. Серверу нужен локальный исполнитель с uvx и доступом к API. [Установка и подключение](https://github.com/grebennikovxyz/ya-webmaster-metrica-plugin#установка)
